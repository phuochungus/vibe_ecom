# Golf Store - Customer Frontend

Shopee-inspired e-commerce frontend for golf equipment sales built with React, TypeScript, and Ant Design.

## Tech Stack

- **React 19** - UI library
- **TypeScript** - Type safety
- **Vite** - Build tool
- **Ant Design 5.x** - UI component library
- **TanStack Query** - Server state management
- **React Router DOM v6** - Routing
- **Axios** - HTTP client

## Getting Started

### Prerequisites

- Node.js 18+
- Backend API running on `http://localhost:8080`

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

App runs on `http://localhost:3001`

### Build

```bash
npm run build
```

Output in `dist/` directory.

✅ Authentication, Product Browsing, Shopping Cart, Checkout, PAYOS Payment, Order Management, Order Tracking, Notifications
